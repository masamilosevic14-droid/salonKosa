# Studio Kosa — sajt

Statički sajt spreman za GitHub Pages.

1. Napravite novi repozitorijum na GitHub-u i otpremite SADRŽAJ ovog foldera (index.html mora biti u korenu).
2. Settings → Pages → Source: "Deploy from a branch", grana `main`, folder `/ (root)` → Save.
3. Sajt će biti dostupan na https://<korisnik>.github.io/<repozitorijum>/

Stranice: index.html (Početna), galerija.html, nega.html, usluge.html.
Fajl .nojekyll je potreban da bi se učitale slike iz .image-slots.state.json.
